
# CLI Expense & Bill Splitter

A simple command-line Python tool designed to split restaurant bills and custom fixed tips evenly among a group of people.

## Features
- Calculates base bill split per person.
- Calculates tip split per person based on a total dollar amount.
- Formats all monetary values clearly to two decimal places ($0.00).

## How to Run
1. Ensure you have Python installed on your computer.
2. Open your terminal or command prompt.
3. Run the script:
   python main.py

## Tech Stack
- **Language:** Python 3
- **Built-in Functions:** `input()`, `float()`, `int()`, `print()`, F-string formatting (`:.2f`)
