
# Multi-Unit & Temperature Converter

A simple command-line Python utility designed to convert values between metric and imperial systems, as well as handle temperature conversions.

## Features
- **Distance:** Converts meters to feet and vice versa.
- **Weight:** Converts kilograms to pounds and vice versa.
- **Temperature:** Converts Celsius to Fahrenheit and vice versa.
- **Input Validation:** Built-in error handling prevents crashes from non-numeric inputs.

## How to Run
1. Ensure you have Python installed.
2. Open your terminal or command prompt.
3. Run the script:
   python main.py

## Tech Stack
- **Language:** Python 3
- **Built-in Functions:** `input()`, `float()`, `int()`, `try/except` error handling, f-string formatting (`:.2f`)
